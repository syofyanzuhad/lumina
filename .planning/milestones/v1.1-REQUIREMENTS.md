# Requirements: Milestone v1.1 - Feature Expansion

## Overview

Milestone v1.1 expands Lumina with richer telemetry analytics, deeper insights into custom events and conversion goals, data portability via export formats, and friction-free sharing through secure public dashboard links.

## Functional Requirements

### 1. Enhanced Analytics Data Detection (Phase 11)

- **REQ-DETECT-01**: User-Agent parsing MUST extract detailed Browser name/version (Chrome, Safari, Firefox, Edge, etc.) and OS name/version (macOS, Windows, iOS, Android, Linux).
- **REQ-DETECT-02**: Event ingest and middleware MUST extract Country code / country name (via GeoIP / Cloudflare / server headers) and store it with the event.
- **REQ-DETECT-03**: `AnalyticsService` MUST provide aggregated breakdowns for top Browsers, top Operating Systems, and top Countries for any given site and date range.
- **REQ-DETECT-04**: Dashboard UI (Inertia/Vue and Livewire) MUST render Browser, OS, and Location breakdown tables/cards.

### 2. Custom Event Tracking UI (Phase 12)

- **REQ-EVENT-01**: Dashboard UI MUST display a dedicated Custom Events tab or section listing all tracked custom event names for the selected site.
- **REQ-EVENT-02**: Selecting a custom event MUST display total event count, unique users count, and custom payload metadata breakdown.
- **REQ-EVENT-03**: Livewire embedded component MUST support custom event breakdown parity with standalone Inertia/Vue dashboard.

### 3. Goal & Conversion Tracking (Phase 13)

- **REQ-GOAL-01**: Users MUST be able to create, edit, and delete Goals per site (Pageview URL path target OR Custom Event target).
- **REQ-GOAL-02**: `AnalyticsService` MUST calculate goal completions count and conversion percentage relative to total unique visitors for a selected date range.
- **REQ-GOAL-03**: Dashboard UI MUST display active Goals with completion counts, trend line, and conversion rate percentage.

### 4. Data Export Engine (Phase 14)

- **REQ-EXPORT-01**: Users MUST be able to trigger CSV and JSON exports for Pageviews, Custom Events, and Aggregated Analytics.
- **REQ-EXPORT-02**: Export endpoints MUST respect site access policies and date range filters (`from_date`, `to_date`).
- **REQ-EXPORT-03**: UI MUST provide download action buttons in the dashboard with immediate streamed file download.

### 5. Public & Shareable Dashboards (Phase 15)

- **REQ-SHARE-01**: Site owners MUST be able to enable/disable public sharing per site and generate a unique, non-guessable share token or slug.
- **REQ-SHARE-02**: Unauthenticated visitors accessing `/share/{token}` MUST view a read-only version of the analytics dashboard.
- **REQ-SHARE-03**: Shareable links MUST optionally support password protection or domain restriction.

### 6. Verification & E2E (Phase 16)

- **REQ-VFY-01**: Comprehensive feature and integration test suite covering all v1.1 additions with zero regressions on v1.0 features.

## Non-Functional Requirements

- **Performance**: GeoIP and UA parsing MUST add less than 2ms overhead during event queue processing.
- **Security**: Shareable tokens MUST be cryptographic hashes; share endpoints MUST be strictly read-only and prevent access to site management or user settings.
- **Compatibility**: Retain full backwards compatibility with existing `lumina-core` API and v1.0 tracking scripts.
